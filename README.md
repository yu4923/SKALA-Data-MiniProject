# DAY 2 - 모델 학습 및 평가

## 선형회귀

cycle_life를 Y로 사용하고, 하이퍼파라미터 튜닝 없이 선형회귀를 학습했다. Batch 1의 46개 셀을 학습 35개와 Hold-out 검증 11개로 나누고, 수명이 있는 Batch 2의 39개 셀로 최종 평가했다.

Hold-out은 충전 프로토콜별로 분리했으며, Train 성능은 Hold-out을 제외한 학습 데이터에서 동일 프로토콜이 겹치지 않도록 나눈 5-fold CV의 평균이다. 결측값 처리, 수치형 피쳐 표준화와 충전 프로토콜 인코딩은 각 학습 구간에서 계산했다.

| 구분 | MAPE (%) | 비고 |
| --- | ---: | --- |
| Train (Batch 1 CV) | 24,753.45 | 5-fold CV 평균 |
| Valid (Batch 1 Hold-out) | 24,802.87 | 학습에 사용하지 않은 셀·프로토콜 |
| Test (Batch 2) | 122,044.14 | Batch 2 최종 평가 |
| Gap (Train-Valid) | +49.42 | (+): 과적합 의심 |
| Gap (Valid-Test) | +97,241.26 | (+): 배치 간 일반화 저하 의심 |
| Gap (Target-Test) | +122,035.04 | Target: 원논문 9.1% |

Gap은 각각 Valid − Train, Test − Valid, Test − Target으로 계산하며 단위는 %p이다.

선형회귀는 Train과 Valid 모두 오차가 크게 나타났고, Batch 2에서는 더 크게 증가했다. 현재 구성에서는 수명을 제대로 예측하지 못했으며, 논문 Target인 9.1%에도 미치지 못했다.

# DAY 1 - 배터리 수명 EDA

## Dataset

Stanford & MIT의 배터리 수명 데이터셋으로, *Data-driven prediction of battery cycle life before capacity degradation* (Nature Energy, 2019)에 사용된 데이터이다.

2017-05-12, 2018-02-20, 2018-04-12의 세 Batch를 사용했다. 배터리별 cycle_life와 충전 프로토콜, 사이클별 방전·충전 용량, 내부 저항, 온도, 충전 시간, 전압과 전류를 확인하고 Batch별로 비교했다.

## Question

### 1. Cycle Life 분포는 어떻게 생겼는가?

- 150~2,300 사이클 Histogram
- 장수명(>1,000)/단수명(<500) 비율 확인
- 이상치 셀 식별 - 왜 유독 짧은가?

Batch별 히스토그램과 박스플롯으로 수명 분포를 비교했다. 단수명 셀은 Batch 2에 집중되어 있었으며, 다른 셀보다 내부 저항이 높은 구간의 비율이 크게 나타났다. 박스플롯의 장수명 이상치도 다른 셀과 피쳐 평균을 비교했다.

### 2. 열화 곡선 - 방전 용량이 어떻게 감소하는가?

- 사이클별 Qd 추이 시각화
- 열화 속도가 일정한가, 가속되는가?
- Knee point - 급격한 열화 시작점 탐색

전체 데이터와 용량 이상값을 필터링한 데이터의 QD 곡선을 비교했다. 대부분의 셀은 처음에는 완만하게 감소하다가 수명 후반에 감소 속도가 빨라지는 모습을 보였다. 곡선의 기울기가 급격하게 변하는 부분을 Knee point 탐색 대상으로 보았다.

### 3. ΔQ(V) 곡선 - 초기 사이클에서 차이가 보이는가?

- 사이클 100번 - 사이클 10번의 Q(V) 차이 계산
- 장수명 셀 vs 단수명 셀의 ΔQ 형태 비교
- 이를 구분할 수 있는 통계값으로 피쳐 추출

ΔQ(V) = Q100(V) - Q10(V)를 계산하고, 수명별 대표 셀의 세 전압 지점과 전체 곡선을 비교했다. 수명이 짧을수록 음수 방향의 변화가 큰 경향이 나타났지만, Batch 3에서는 장수명 셀도 양수 방향으로 크게 변화했다. 변화 폭과 음수 방향의 변화 정도를 함께 보기 위해 분산과 최솟값을 피쳐로 사용했다.

### 4. 충전 조건 (C-rate)과 수명의 관계는?

- 충전 프로토콜별 평균 수명 비교
- 고속 충전 셀이 정말 수명이 짧은가?
- 충전 전류 패턴과 열화 속도 상관 분석

Batch별 충전 프로토콜의 평균 수명을 비교하고, 충전 전류와 cycle_life의 관계를 확인했다. 전체 사이클의 전류 평균·표준편차·95백분위 값과 QD 감소 기울기로 충전 전류 패턴과 평균 열화 속도의 상관관계도 비교했다. Batch 2에서는 newstructure가 붙은 프로토콜의 평균 수명이 더 길게 나타났다.

### 5. 상관관계 - 어떤 신호가 수명과 연관되어 있는가?

- 초기 사이클 피쳐들과 Cycle Life 상관계수 확인
- 가장 강한 관계 식별
- 다중공선성 문제 확인

cycle_life를 Y로 두고 Summary, ΔQ(V), 충전 전류 피쳐의 상관계수를 비교했다. 절댓값 기준 가장 강한 Pearson 상관은 Batch 1에서 std_current_A(-0.901), Batch 2에서 delta_Q_min(0.819), Batch 3에서 p95_current_A(-0.708)로 나타났다. mean_Tmax와 mean_Tavg 등 온도 피쳐 사이에도 높은 상관이 나타났다.
